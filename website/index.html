Features

Everything you need to
manage your team effectively

From real-time monitoring to detailed analytics — TeamMonitor gives you complete visibility into how work gets done.

📊

Live Activity Dashboard

See every employee's current status, active application, and session duration in real-time. Know exactly who's working and on what.

📸

Encrypted Screenshots

Periodic screenshots are captured on employee machines, encrypted with AES-256-GCM before upload, and decrypted only when viewed by admins.

🖥️

App Usage Tracking

Automatically tracks which applications employees use and for how long. Categorize apps as productive or unproductive with custom rules.

⚡

Productivity Scoring

Automatic productivity scores based on app usage and idle time. Define your own policy — mark apps as productive or unproductive per your team's workflow.

⏱️

Time & Attendance

Accurate punch-in/out tracking with idle detection. Session durations account for idle time so you see actual working hours, not just logged hours.

📈

Reports & Analytics

Weekly hour charts, app usage breakdowns, per-employee analytics, longest sessions, and productivity trends — all in one reports view.

📋

Projects & Tasks

Kanban-style project and task management. Employees track time against specific tasks, giving you a clear picture of where hours are really going.

🏖️

Leave Management

Employees submit leave requests, admins approve or deny them. Leave balances tracked automatically alongside attendance records.

How it works

Up and running in minutes

Three simple steps and your whole team is being tracked automatically.

1

Deploy the backend

Host the Node.js server on your own cPanel, VPS, or cloud. Point it at a MySQL database. Set two environment variables and you're live.

2

Install the macOS agent

Download TeamMonitorAgent.app and install it on each employee's Mac. It runs silently in the menu bar and starts tracking on punch-in.

3

Monitor from anywhere

Open the admin panel in any browser. See live sessions, screenshots, productivity scores, and detailed reports across your entire team.

Security & Privacy

Your data never leaves
your server

TeamMonitor keeps your data encrypted and private. No third-party surveillance, no data sharing. You own every byte.

🔐
AES-256-GCM encrypted screenshots
Screenshots are encrypted before being written to disk using a key only you control. Even server admins can't view them without the key.
🛡️
JWT authentication
Every API request requires a signed JWT token. Employees can only access their own data — admins control everything else.
🗄️
Secure MySQL storage
All session data, activity logs, and screenshots are stored in a dedicated MySQL database. No vendor lock-in, no shared infrastructure.
🔒
Role-based access control
Admins see everything. Employees see only their own data. Granular permissions for screenshots, leave management, and reports.
🔐

Productivity

Custom productivity
policies per team

Not every team uses the same apps. Define your own rules — mark Figma as productive for designers, coding tools for engineers.

⚙️
Custom app rules
Label any app as Productive, Unproductive, or Neutral. Rules apply globally across all employees. Update them any time.
🎯
Accurate scoring
When custom rules are active, score = productive time ÷ (productive + unproductive). Neutral apps don't dilute the score.
💡
Idle-aware tracking
IOKit idle detection removes AFK time from session totals. Hours tracked reflect actual work, not time the computer was left on.
📊
Historical trends
Compare productivity week over week. Spot patterns in app usage, session lengths, and team habits across any date range.
Integrations

Works with your existing stack

Connect your tools to make TeamMonitor even more powerful. Link time tracking directly to the work being done.

🔷
Jira
Connect per-employee Jira accounts. Browse and assign issues directly from the macOS agent. Track time against specific Jira tickets.
🍎
macOS Native
Pure Swift/SwiftUI app. No Electron, no browser wrapper. Lightweight menu bar agent with minimal CPU and memory footprint.
🗄️
MySQL
Store all data in your own MySQL database. Also supports SQLite for local development. Full schema migrations run automatically.
🌐
Any Browser
The admin panel is a React web app. Works in Chrome, Safari, Firefox — no desktop app needed for management. Responsive on mobile too.
